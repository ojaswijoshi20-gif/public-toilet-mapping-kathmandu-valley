# Spatial Distribution, Field Verification, and Condition Assessment of Public Toilets in Selected Heritage Areas of Kathmandu Valley
## Project Status

 Planning Phase
Current Activities:
- Project design
- Survey questionnaire development
- Data dictionary preparation
- Review of existing toilet datasets
- Preparation for field data collection
  
## Project Overview:
This project maps and assesses the condition of publicly accessible toilets in selected heritage areas:
Kathmandu Durbar Square,
Patan Durbar Square,
Bhaktapur Durbar Square.

## Objectives:
Identify public toilet locations.
Assess facility conditions.
Evaluate accessibility and service availability.
Visualize findings using GIS.

## Methodology

The project will use field observation and GIS-based mapping to assess publicly accessible toilets within selected heritage areas of Kathmandu Valley.
Existing online toilet directories will be reviewed prior to field verification. Final analysis will be based on direct field observation, GPS coordinate collection, and facility assessment.
